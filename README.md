# דשבורד ריצה — Adi Schlesinger

דשבורד סטטי ואינטראקטיבי של נתוני ריצה ובריאות מ־Garmin Connect, מוכן ל־GitHub Pages.

## מה יש כאן

- סיכומי ריצה: ק״מ חודשי/שבועי, יחס עומס חריף:כרוני, טיפוס לק״מ, קצב מול דופק בריצות קלות, התפלגות מרחקים וימי שבוע, שיאים.
- מדדי בריאות שבועיים: דופק מנוחה, HRV, משך שינה, סטרס, Body Battery, VO2max, משקל, ופיזור ק״מ מול סטרס.
- סינון טווח תאריכים ו־tooltips.

## מבנה

```
index.html          # הממשק (RTL עברית, ערכת נושא כהה, Chart.js מ־CDN)
assets/hero.jpg     # תמונת כותרת (ללא EXIF)
data/*.json         # נתונים מצטברים בלבד
```
